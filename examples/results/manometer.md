# Манометр МД-100 — 0–1,6 МПа, корпус 100 мм

## SEO-описание

Манометр МД-100 производителя ДемоПрибор предназначен для визуального контроля избыточного давления воды и воздуха. Показания отображаются стрелкой на шкале, поэтому результат считывают непосредственно в месте установки. Прибор применяется для местного наблюдения за давлением в трубопроводе. Его можно рассматривать при подборе показывающего манометра для этой задачи, сопоставляя параметры с требованиями конкретной точки измерения.

Диапазон измерений составляет 0–1,6 МПа, класс точности — 1,5. Диаметр корпуса — 100 мм. Для установки предусмотрено резьбовое присоединение G1/2. Эти характеристики помогают сравнить прибор по диапазону, классу точности, размеру корпуса и способу подключения. Перед выбором нужно сопоставить присоединение с местом установки, а диапазон — с требуемыми условиями измерения. Дистанционная передача показаний не предусмотрена: данная модель рассчитана на местное считывание. При подготовке заявки можно указать название МД-100 и перечисленные параметры, чтобы менеджер проверил соответствие прибора задаче.
