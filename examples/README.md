# Демонстрационные товары

МД-100, ТД-200 и производитель «ДемоПрибор» вымышлены. Значения созданы для проверки прототипа и не относятся к реальной продукции.

В примере манометра все поля заполнены. В примере термометра отсутствуют тип подключаемого датчика, интерфейс передачи данных и степень защиты корпуса; эти значения должны остаться «данных нет».

В `results/` лежат вручную подготовленные эталоны результата: JSON с карточкой и замечаниями и его Markdown-представление. Это примеры требуемого формата.

В `generated/` находятся реальные результаты `nvidia/nemotron-3.5-super-vl:free` от 7 ноября 2026 года, полученные с отключёнными рассуждениями через OpenRouter. В `check.json` сохранены параметры и показатели этого прогона. Исходные товары для него также вымышлены.
